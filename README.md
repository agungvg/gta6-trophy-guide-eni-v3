Sunset Ledger — a dark Vice-night trophy guide and tracker for GTA VI. All 55 trophies (1 Platinum, 2 Gold, 6 Silver, 46 Bronze) with a plain-English guide for each, verified 55/55 against the kit's official list. A tracker tab with per-trophy progress, localStorage persistence, export/import JSON, filters (kind, grade, earned, missable, PSN-hidden), search and sorts, plus a spoiler shield for the 28 PSN-hidden trophies. A 3-stage roadmap to the platinum (~200 h), a missables page led by the one possibly missable trophy (Positive Mental Attitude — do the Chapter 1 balcony meditation), and a sources page that shows both sides wherever the guides disagree instead of picking one silently. Static and offline — nothing leaves your browser.

## Run it
```sh
node serve.ts
# then open http://localhost:8080
```
